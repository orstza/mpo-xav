## mpo-xav
- Mildly Provisioned &amp; Orchestrated XAV.
- Bare-bone TFTP and HTTP server integrated with iPXE.
- Optimal performance for minimal code and dependencies.
- Bring Your Own DHCP Server (BYODS).
- Aims to bare-metal provisions a diskless boot with multiple PCs.
- Require familiarity with [mkosi](https://mkosi.systemd.io) (for now).
